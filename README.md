## 对应PPT知识点
1. 数据并行（DDP）：多GPU各自持有完整模型副本，前向传播独立计算，反向传播后跨卡同步梯度。
2. 流水线并行：将模型切分成多个阶段，不同GPU执行不同层，流水线方式执行，提升算力利用率。
3. 张量并行：把单层模型的权重矩阵切分到多卡，单步计算分布式完成。
4. 3D并行 = 数据并行 + 流水线并行 + 张量并行组合。
5. ZeRO优化：拆分优化器状态、梯度、模型参数到不同GPU，降低单卡显存开销。
